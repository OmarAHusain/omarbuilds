# omarbuilds.com

Static site for OmarBuilds. Zero dependencies — one Node script builds everything into `dist/`.

```
npm run build   # → dist/
npm run serve   # build + local preview at http://localhost:8080
```

## Layout

| Path | What |
|---|---|
| `content/site.json` | All copy, links, featured builds, Patreon tiers (USD). Edit this first. |
| `content/press/*.md` | Archived press articles (see below). |
| `content/press/images/` | Images for archived articles. |
| `content/videos-cache.json` | Last successful YouTube feed fetch. Auto-updated by the build; used as fallback if YouTube is unreachable. |
| `content/stats-cache.json` | Last known follower counts (YouTube, Instagram, TikTok, Patreon). Scraped at build time with no API keys; each platform falls back to its cached value if the scrape fails. The weekly workflow commits both caches back so the fallback stays fresh. |
| `media/` | Brand assets (`profile.jpg` and `og-banner.jpg` are the resized ones the site uses). |
| `src/styles.css` | All styling. |
| `build.mjs` | The build. Fetches the channel RSS, renders `/`, `/press/`, `/press/<slug>/`, `/links/`. |

Pages:
- `/` — hero + latest videos (from YouTube RSS, auto) + builds + Patreon + press + about
- `/links/` — link-in-bio page for Instagram/TikTok
- `/press/` — index of archived coverage
- `/press/<slug>/` — full archived copy with link to the original

## Adding a press article

Create `content/press/YYYY-MM-DD-slug.md`:

```md
---
slug: short-slug
title: Article headline
sourceName: Publication name
sourceUrl: https://original.url/
author: Writer name
date: 2026-08-14
retrieved: 2026-08-28
image: short-slug.jpg        # optional, put file in content/press/images/
excerpt: One-line standfirst  # optional
build: Doc Ock's Robot Claw   # optional, adds a "build it yourself" CTA
---

Article body in markdown (headings, paragraphs, lists, links, bold, images).
```

Drop the article's image in `content/press/images/`. Archive pages are `noindex` so they don't compete with the original in search, and they carry a clear "courtesy archive / rights remain with the publisher" notice plus links to the original and the Wayback Machine. Tip: also submit the original URL at https://web.archive.org/save so there's an independent copy.

To link a build card to an article, set `"press": "<slug>"` on the build in `site.json`.

## Adding a featured build

Add an object to `builds` in `content/site.json` with `title`, `status`, `summary`, `videoId`, `patreon` (true/false).

## Deploying

The build output is a plain folder; any static host works. DNS for omarbuilds.com is on Route 53.

**GitHub Pages (wired up):** `.github/workflows/build.yml` builds on push and weekly (Mondays 06:17 UTC) so new videos and follower counts refresh without a commit; trigger it manually any time from the Actions tab (*Run workflow*). Enable in repo → Settings → Pages → Source: *GitHub Actions*. Then in Route 53 add:
- `A` @ → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- `AAAA` @ → `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
- `CNAME` www → `<user>.github.io`

Set the custom domain in Pages settings (the `CNAME` file is generated by the build) and tick *Enforce HTTPS*.

**Netlify:** connect the repo; `netlify.toml` already sets the build. For the weekly refresh, create a Build Hook in Netlify and replace the deploy job in the workflow with `curl -X POST "$NETLIFY_BUILD_HOOK"`. Point Route 53 at Netlify per their DNS instructions.

**S3 + CloudFront:** sync `dist/` to a bucket (`aws s3 sync dist/ s3://omarbuilds.com --delete`) behind a CloudFront distribution with an ACM cert; alias the Route 53 A record to the distribution. Add that sync as the deploy step in the workflow.
